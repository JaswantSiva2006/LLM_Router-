CORTEX / ADAPTIVE INFERENCE RESEARCH

Intelligence takes
a different path.

Today’s AI models take the same path through every layer, no matter the question. Cortex is building a router that adapts the path to the problem—executing, skipping, or revisiting layers as needed.

Same model.
Different route.

02 / EARLY EVIDENCE

The search found
paths worth learning.

Before training a router, we searched for alternate paths through a 28-layer baseline model on a pilot set of math questions. This produced candidate routes and training labels—not a deployed speedup claim.

Among the 198 accepted routes, offline search found 62 shorter correct routes for baseline-correct questions and 136 corrections where the baseline answer was wrong. These are search results on the pilot set. They do not show that a trained router generalizes, runs faster, or improves the model on unseen questions.

03 / THE STANDARD

The benchmark
has to be real.

Better paths in an offline search are the beginning. The product exists only if a trained router makes better decisions on unseen inputs and the full system wins on real hardware.

PROOF PLAN / HELD-OUT EVALUATIONIN PROGRESS
  1. 01

    Keep quality. Use less compute.

    Compare answer accuracy against the unchanged model while measuring executed layers and GPU work.

  2. 02

    Keep compute. Solve more.

    Test whether revisiting layers improves verified task success at a comparable compute budget.

  3. 03

    Count the entire cost.

    Measure end-to-end latency, router overhead, and throughput on held-out workloads—not layer counts alone.
